# Power BI Dashboard Projects

This repository contains three Power BI dashboard projects developed using Power BI Desktop, DAX, and CSV datasets.

## Projects

### Task 1 – Sales Performance Dashboard
- Sales Analysis
- Profit Analysis
- KPI Cards
- Monthly, Quarterly, and Yearly Sales
- Product, Region, and Sales Representative Filters

### Task 2 – Employee Performance Dashboard
- Employee Productivity
- Attendance Analysis
- Department-wise Performance
- KPI Cards
- Department, Designation, and Reporting Period Filters

### Task 3 – Student Performance Dashboard
- Subject-wise Performance
- Class-wise Performance
- Attendance Percentage
- Topper List
- Grade Distribution
- Class, Subject, and Academic Session Filters

## Tools Used
- Power BI Desktop
- DAX
- CSV Datasets
